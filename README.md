es una plataforma web donde los usuarios pueden comprar y vender motos y también contratar seguros para sus vehículos. Desarrollado con tecnologías front-end: HTML5, CSS3 y JavaScript.
✅ Catálogo de motos (nuevas y usadas) con filtros por marca, modelo y precio.
✅ Publicación de anuncios para vender motos (formulario interactivo).
✅ Cotización de seguros en tiempo real (simulación con JavaScript).
Frontend: HTML5, CSS3, JavaScript (ES6+).

Estilos: Flexbox, Grid, Animaciones CSS.

Almacenamiento: LocalStorage (para guardar datos temporales)
